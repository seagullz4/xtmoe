# 常用操作

日常只需运行 `xtmoe on`，按模式和编号选择容器。0 或空输入返回；EOF 取消操作。程序维护、代理、服务、数据和网络均从菜单进入。

| 需求 | 入口 |
| --- | --- |
| 安装/进入/停止 Ubuntu | PRoot 或 Chroot → 容器管理 |
| 恢复/备份/重装/删除 | 对应模式 → 数据管理 |
| 启停 Docker/systemd | Chroot → 服务菜单 |
| PRoot SSH端口与启动 | PRoot → 容器运行管理；停止活动会话会一并停止SSH |
| 地址、DNS、端口映射 | Chroot → 网络与 DNS |
| 修改代理 | 首页 → 代理设置 |
| 故障后续跑安装 | Chroot → 诊断与修复 |
| 更新或卸载程序 | 首页 → 程序维护；更新也可用 `xtmoe update` |
| 放弃源码本地修改并更新 | `xtmoe update --force` 或程序维护 → 强制更新（需确认） |

快捷命令以 `xtmoe help` 为准。不提供旧版高级命令别名。通过菜单执行的容器命令会在选中的系统中运行；必须看清名称。

局域网映射添加时只输入宿主端口（如 `18080`）即采用自动模式，随 Wi-Fi/热点/有线 LAN 的私网 IP 变化重绑定；需要固定地址时输入 `IPv4:端口`。断网保留配置并暂停映射，重连后自动恢复；查看映射列表可看到当前访问地址。旧固定映射要先删除再添加自动模式。

删除、重装会损失目标系统数据；操作前备份。卸载程序与删除容器不同。安装和更新不主动覆盖同名容器，后台服务状态根据实际进程判断。
