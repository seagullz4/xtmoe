# v1.0.0 架构

入口分为小型公开 CLI 和中文交互向导，两者复用内部操作。菜单直接调用库函数，不借助隐藏 CLI 或执行用户配置。

- common / capabilities：平台、ABI、依赖、公开命令策略和能力报告。
- proot：当前 proot-distro 的原生镜像、会话和数据操作。
- chroot：可恢复安装阶段、基础用户空间、服务与数据编排。
- manager：列表、编号选择、菜单和取消语义。
- proxy：严格解析与受控代理同步。
- Root 助手：验证路径/权限后执行挂载、namespace、生命周期和数据操作。
- network 助手：网络配置、资源归属、策略路由/NAT、映射、代理转接和异常回收。

配置、用户数据和缓存分别存放。Root 前只传递明确参数与代理白名单。Root 输出不是配置脚本，PID 与启动时间共同核验，规则按精确归属清理。

自动方案首先判断基本能力，再选择增强；实际配置和服务验证是独立阶段。能力缺失可跳过增强，运行故障则标记 partial 并保留现场。已有显式模式不自动改变。

安装器加锁后将完整程序暂存到独立版本目录，校验全部 Shell 语法和版本，再原子切换 current 指针。稳定入口只解析一次指针；运行中的命令和 Root/网络助手始终引用原版本目录，不热覆盖文件。旧版本目录不自动回收，避免破坏长期运行助手；首次从旧布局更新也保留旧模块。更新另有源码更新锁，并拒绝覆盖未提交变更。

恢复先完整读取归档清单，再独立校验路径；清单读取或校验失败均拒绝解压。随机私有暂存目录在失败/可捕获信号后回收，验证容器结构后才迁入目标。删除检查目标路径、标记、运行状态及挂载，不能对宽泛目录递归删除。
